### 2025. 09. 23. { #september-23-2025 }

<a id="september-23-2025-feature-updates"></a>
#### 機能改善・変更

* [コンソール] 送信履歴の検索結果をダウンロードする際に「既読/未読」フィールドを追加
    * 通常の送信履歴の検索結果をダウンロードしたファイルに、「既読/未読」フィールドが追加されました。
    * 受信者のメール開封状況を、より簡単に確認・分析できるようになりました。
    * 従来の検索結果ダウンロード機能では提供されていなかった開封状況の情報を通じて、メール送信の効果をより正確に測定できるようになります。

<a id="september-23-2025-bug-fixes"></a>
#### バグ修正

* [SMTP] サブドメイン検証ロジックの改善
    * SMTPサブドメインを使用してメールを送信する際に発生していた認証失敗の問題が修正されました。
    * サブドメインに対するSPF、DKIM、DMARC認証を全て完了しているにもかかわらず、認証失敗によりメールが送信されなかった現象が改善されました。

<a id="may-27-2025"></a>
### 2025. 05. 27. { #may-27-2025 }

<a id="may-27-2025-feature-updates"></a>
#### 機能改善・変更

* [コンソール]受信拒否時の通知内容の改善
    * メール受信者が受信拒否リンクをクリックした場合に表示される通知内容が改善されました。
    * 変更前：受信者のアドレスと受信拒否ボタンが表示されていました。
    * 変更後：送信者と受信拒否日時が表示されます。
    * 「送信者名<送信元メールアドレス>」形式で送信した場合、受信拒否リンクをクリックすると送信者名と送信元メールアドレスが表示されます。
        * 送信者名を入力しない場合は、送信元メールアドレスのみが表示されます。
    * この機能は5月27日以降に送信されたメールに適用され、既に送信済みのメールには適用されません。

<a id="april-29-2025"></a>
### 2025. 04. 29. { #april-29-2025 }

<a id="april-29-2025-feature-updates"></a>
#### 機能改善・変更

* [API]ワンクリック受信拒否機能のポリシー変更
    * Gmailの送信者ガイドラインの強化に伴い、追加されたワンクリック受信拒否機能のポリシーが変更されました。
    * 変更前：受信者に送信する全てのメールに対して、ワンクリック受信拒否機能が提供されていました。
    * 変更後：受信者に送信するメールのうち、広告メールに限りワンクリック受信拒否機能が提供されます。
    * 一般メール、認証メールでワンクリック受信拒否を使用したい場合は、`customHeaders`に
      `List-Unsubscribe-Post: List-Unsubscribe=One-Click`を追加して使用できます。
        * その際、ワンクリック受信拒否のURLはユーザーが直接作成する必要があり、サービス側で内部的に自動生成されたリンクは提供されません。

<a id="march-11-2025"></a>
### 2025. 03. 11. { #march-11-2025 }

<a id="march-11-2025-added-features"></a>
#### 機能追加

* [API]メール送信アップデート完了リスト照会API追加
    * Emailサービスで送信処理が完了したメールの送信ステータスを照会できるAPIを追加しました。
    * 該当APIはメッセージ送信結果アップデート時間を基準に検索されます。
    * 送信結果がアップデートされる基準は次のとおりです。
        * メールが受信完了した場合(受信SMTPから受信完了レスポンスを受け取った場合)
        * メール送信処理間で送信失敗処理された場合(受信拒否、ホワイトリストなど)
* [コンソール]返信メール設定オプション機能を追加
    * 返信メール設定オプションを追加して返信メール受信の有無を設定できます。
    * no-reply, noreplyをメールアドレスに設定すると、返信設定の有無に関わらず返信メールを受信しません。
* [API] v2.1広告メール送信/認証メール送信API senderGroupingKey追加
    * 広告メール送信/認証メール送信APIにsenderGroupingKeyを追加して発信者グループキーを設定できます。

<a id="march-11-2025-feature-updates"></a>
#### 機能改善・変更

* [API]メール既読イベント処理エラーを修正
    * 一部状況でメール送信が完了していない状態で既読処理される問題を改善しました。
* [コンソール] Freemarkerテンプレートプレビュー機能を改善
    * Freemarkerテンプレートプレビュー時、テンプレートパラメータを全体適用しない場合、適用しないパラメータを確認できるように改善しました。
* [API]テンプレート送信の有効性を改善
    * テンプレート送信時テンプレートパラメータが欠落している場合でも、テンプレート原文が送信される問題を改善しました。
    * テンプレート送信時、テンプレートパラメータが欠落している場合、送信が失敗処理されます。

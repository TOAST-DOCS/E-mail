#### 기능 개선

* [콘솔, API] 도메인 TLD 분류 기준 개선
    * 최상위 도메인(TLD) 분류 기준을 개선하여 기존에 서브도메인으로 분류되던 일부 도메인이 정상적으로 분류되도록 수정했습니다.

### 2026. 05. 27. { #notification-email-release-notes-1 }

<a id="notification-email-release-notes-1-1"></a>

#### 버그 수정

* [API] 수신 거부 링크 호출 실패 문제 개선
    * 발송된 메일 내 수신 거부 링크 클릭 시 일부 경우에서 호출이 실패하던 문제가 수정되었습니다.
    * 기존에 발송된 수신 거부 링크도 변경 후 정상적으로 동작합니다.
* [API] 비ASCII 문자가 포함된 도메인 처리 개선
    * 액센트 기호 등 비ASCII 문자가 포함된 도메인(예: `münchen.de`)으로 도메인 등록을 요청하거나 메일 발송을 요청하는 경우 오류 응답이 반환되도록 변경되었습니다.
    * RFC 1123 기준(영문자, 숫자, 하이픈, 점)을 따르지 않는 도메인 요청을 차단하여 발송 안정성이 개선됩니다.
    * 국제화 도메인을 사용해야 하는 경우, Punycode(예: `xn--mnchen-3ya.de`) 형식으로 변환하여 요청하세요.

### 2026. 03. 24. { #march-24-2026 }
<a id="march-24-2026-feature-updates"></a>

#### 기능 변경
* [콘솔, API] 태그(Tag) 메일 발송 기능 지원 종료
    * 태그 관리, UID 관리, 태그 메일 발송 관련 기능의 지원이 종료됩니다.
    * 콘솔에서 **태그 메일 발송 조회**, **태그 관리**, **UID 관리** 메뉴가 삭제됩니다.
    * 태그 관리, UID 관리, 태그 메일 발송 관련 API 호출 시 지원 종료 응답이 반환됩니다.
* [콘솔] 메시지 발송 내역 백업 결과 알림 추가
    * 메시지 보관 기간이 지난 메시지 발송 내역의 백업 설정 시 결과 알림을 받을 수 있습니다.
    * **프로젝트 대시보드 > 알림 관리**에서 설정할 수 있습니다.
